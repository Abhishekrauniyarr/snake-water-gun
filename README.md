
# Snake, Water, Gun Game

A simple Python command-line game where the player competes against the computer in Snake, Water, and Gun.

## Features

- User choice selection
- Random computer selection
- Win, lose, and tie conditions
- Built using Python's `random` module

## Requirements

- Python 3.x

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the following command:

   ```bash
   python main.py
   ```

## Choices

| Key | Choice |
|:---:|:---|
| `s` | Snake |
| `a` | Water |
| `d` | Gun |

## Technologies Used

- Python
- Random module
